# 🌤️ Weather Dashboard: Global 5-Day Forecast

A beautiful, responsive weather application built using **Python and Streamlit**. It provides current conditions and a 5-day forecast for major cities worldwide, featuring a dynamic background that visually adapts to the current weather.

---

## ✨ Key Features

* **Expanded City Support:** Includes forecasts for **London, Paris, Tokyo, New York, Dubai, Islamabad (Pakistan),** and **Rome (Italy)**.
* **Dynamic UI:** The background gradient changes dynamically based on the current weather condition (Sunny, Cloudy, or Rainy) for the selected city.
* **Current Metrics:** Detailed real-time information: temperature, 'feels like,' humidity, wind speed, visibility, and atmospheric pressure.
* **5-Day Forecast:** Displays daily high/low temperatures and conditions for the next five days.
* **Search Functionality:** Allows users to easily search and switch between the available cities.
* **Glassmorphism Inspired:** Uses custom CSS to achieve a clean, modern "glass" effect over the dynamic background.

---

## 💻 Tech Stack

* **Frontend/App Framework:** **Streamlit** (Python) for creating the interactive web interface.
* **Core Logic:** **Python** for data processing and managing application state.
* **Styling:** **Custom Markdown/CSS** to achieve the dynamic background and glassmorphism effect.

---

## 🚀 How to Run Locally

### Prerequisites
Ensure you have **Python 3.8+** installed on your system.

### Installation
1.  **Clone the repository:**
    ```bash
    git clone [YOUR_REPOSITORY_URL]
    cd [Your-Repository-Name]
    ```
2.  **Install dependencies** using the `requirements.txt` file:
    ```bash
    pip install -r requirements.txt
    ```
3.  **Run the Streamlit application:**
    ```bash
    streamlit run main.py
    ```
The application will open automatically in your web browser.
